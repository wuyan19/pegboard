# CONVENTIONS.md

## 错误处理

- **core**：每个模块定义独立 `Error` 枚举，用 `thiserror`。不跨模块复用错误类型。
- **server**：统一映射为 `ApiError`，映射集中在 `ingress/error.rs`。
- **禁止** `anyhow` 出现在 core 与 server 的公开接口；CLI 顶层可用。
- **禁止** 非测试代码中的 `unwrap` / `expect`；用 `?` 或显式处理。
- **禁止** `panic!` 处理可恢复错误。

## 模块导出

- `mod.rs` 只 `pub use` 对外接口；子模块默认私有。
- 跨模块引用走 `mod.rs`，不写深层路径（`crate::app::internal::x` 禁止）。
- 公开类型全部 `pub`，字段按需 `pub`；构造用 `pub fn new`。

## 命名

- 类型：`UpperCamelCase`。
- 函数 / 变量 / 模块：`snake_case`。
- 常量：`SCREAMING_SNAKE_CASE`。
- 错误变体：`UpperCamelCase`，描述性（`QuotaExceeded`，非 `Err1`）。
- 布尔：`is_` / `has_` / `should_` 前缀。

## 异步与阻塞

- core 的 `store` / `files` 同步；server 侧用 `tokio::task::spawn_blocking` 包装。
- core 的 `proxy` 异步；直接 `await`。
- **禁止** 在 async 上下文中直接调用阻塞 IO。
- **禁止** 跨 `await` 持有 `MutexGuard` / `RwLockGuard`。

## 锁

- 短持有：取数据 → `Arc::clone` → 释放 → 使用。
- `AppState.apps` 用 `RwLock`；读多写少。
- `StoreManager` / `FilesManager` 内部 `Mutex` 保护 map；调用方不感知。

## 日志

- 用 `tracing`，不用 `println!` / `eprintln!`（CLI 顶层错误除外）。
- 结构化字段：`app_id`、`subject`、`action`、`duration_ms`。
- **禁止** 记录：请求体、响应体、凭据、cookie、authorization、文件内容。
- 审计日志独立，写文件，不走 `tracing`。

## 测试

- 单元测试放模块内 `#[cfg(test)] mod tests`。
- 集成测试放 `tests/`，一个文件一个主题。
- 契约测试与 `docs/契约.md` 同步；契约变，测试变。
- 临时目录用 `tempfile`，不写固定路径。
- 异步测试用 `#[tokio::test]`，不手动建 runtime。
- **禁止** 测试间共享可变状态；每个测试自建环境。

## 依赖方向

```
cli → server → core
        ↓
       sdk（静态资源）
```

- core 不依赖 server / cli。
- server 不依赖 cli。
- sdk 零依赖。
- 由 `scripts/check-deps.sh` 检查；反向依赖即 CI 失败。

## 路径安全

- 所有用户输入的路径，`canonicalize` + 前缀检查。
- 禁止直接拼接未校验的路径。
- 应用产物路径由 `AppMeta.root` + 相对路径构成；越界即 404。

## 数据与配额

- 写入前先校验配额，再落盘。
- 任何流式操作（上传、代理）设置上限，超限即断。
- 删除先减引用，内容延迟回收。

## 错误码

- 只用契约定义的错误码；不新增。
- core 错误到错误码的映射，集中在 `ingress/error.rs`。
- 新增错误码需先更新契约文档。

## Git

- 一个任务一个 PR；PR 描述引用任务编号（如 `M3-3.1`）。
- 提交信息：`<模块>: <动作>`，如 `store: add quota check`。
- 不混合格式化与逻辑改动。

## 文档

- 设计变更先改文档，再改代码。
- 契约、存储、SDK 三份文档与代码同步；由 review 把关。
- 新增能力需在契约、SDK、模块三处同时更新。

## 禁止清单

- `anyhow` 在 core / server 公开接口。
- 非测试 `unwrap` / `expect`。
- `println!` / `eprintln!`（CLI 顶层错误除外）。
- 阻塞调用在 async 上下文。
- 跨 `await` 持锁。
- 反向依赖。
- 未校验路径拼接。
- 记录敏感数据到日志。
- 新增契约外错误码。
- 在 handler 内做业务决策（应下沉到 core）。
